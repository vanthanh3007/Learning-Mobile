Điểm kỹ thuật nổi bật

Theo dõi vị trí realtime

Driver đẩy GPS liên tục lên Firebase Realtime Database, có lọc thông minh hai tầng (time gate + distance gate) để không spam khi xe đứng yên. Mất mạng thì điểm GPS xếp vào hàng đợi 100 phần tử lưu ngay trên máy, có mạng lại thì đẩy bù.

GPS chạy nền (Driver)

Android dùng foreground service + wakelock để hệ thống không kill tiến trình; iOS khai báo automotive activity type. Chu kỳ lấy toạ độ do server điều khiển qua cấu hình trả về lúc chạy — chỉnh tần suất tracking mà không cần phát hành bản mới.

Server-driven UI (Ship)

Carousel banner và popup quảng cáo (kéo thả được, hiển thị giữa hoặc cạnh màn hình) render hoàn toàn từ config API — vị trí, ảnh, hành động khi bấm, lớp phủ chặn thao tác đều do backend quyết định.

Form động theo hành động (Driver)

Khi tài xế thao tác trên đơn hàng, server trả về một gói cấu hình form gồm định nghĩa trường, luật kiểm tra dữ liệu và điều kiện hiển thị. App dựng bottom sheet theo cấu hình đó và gửi về đúng API tương ứng. Thêm bước nghiệp vụ mới chỉ cần sửa cấu hình, không đụng tới app.

FCM + Deep Link đủ 3 trạng thái

Xử lý thông báo ở cả foreground, background và khi app đã bị kill. Chạm notification → parse URL → điều hướng thẳng tới đúng đơn hàng, kể cả khi app khởi động từ đầu.

Quản lý menu (Merchant)

Cấu trúc ba tầng nhóm → sản phẩm → thuộc tính, hỗ trợ kéo thả sắp xếp lại, cập nhật hàng loạt và bật/tắt hiển thị từng món.

Tầng API dùng chung

Retrofit sinh code từ khai báo, Dio interceptor tự chèn Bearer token, metadata thiết bị và timezone vào mọi request. Ba app dùng chung tầng này nên hành vi mạng đồng nhất.
