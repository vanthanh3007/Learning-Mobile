Cho thuê xe tự lái — Renter & Owner

Nền tảng cho thuê xe tự lái với 2 luồng người dùng tách biệt: Renter (tìm kiếm, đặt xe) và Owner (quản lý xe, lịch trống, doanh thu). Flutter mobile (~911 Dart files, 96 Cubits) + React JS web.

  • KYC bằng Google MLKit: OCR nhận dạng CMND/CCCD (text recognition), liveness check, xác thực bằng lái xe — toàn bộ xử lý trên thiết bị, không upload raw image.
  • Dual mode: Owner có màn hình riêng hoàn toàn (MainOwnerScreen) với analytics doanh thu, quản lý đội xe, lịch bận theo từng ngày.
  • Pricing engine: Tính giá động theo ngày thuê × đơn giá + phí giao xe + bảo hiểm + VAT − voucher, recalculate realtime khi user thay đổi thông tin.
  • Calendar availability: Firebase Realtime DB sync lịch bận xe realtime — chủ xe cập nhật trên 1 thiết bị, customer thấy ngay.
  • Thanh toán VietQR: Tích hợp VietQR API, quản lý ví, liên kết tài khoản ngân hàng, lịch sử giao dịch.
  • Device fingerprinting: Mỗi request gửi kèm device ID + metadata để server phát hiện gian lận.

Hệ sinh thái giao hàng — Ship / Driver / Merchant

Hệ sinh thái giao hàng gồm 3 Flutter app (~640 file/app): Ship (khách hàng đặt đơn), Driver (tài xế nhận và giao), Merchant (cửa hàng quản lý). Kiến trúc Clean Architecture + Repository Pattern, BLoC/Cubit scoped per screen, GetX cho DI và routing.

  • Real-time tracking: Firebase Realtime Database — driver gửi GPS liên tục với smart filtering (time gate + distance gate), buffer offline queue 100 entries vào SharedPreferences khi mất mạng.
  • Background GPS (Driver): Android foreground service + wakelock, iOS automotive activity type. Config tracking interval được server điều khiển qua ResponseSetting.
  • Server-driven UI (Ship): Carousel banner và popup quảng cáo (draggable, center/side) render hoàn toàn từ config API — vị trí, ảnh, action, barrier overlay đều do backend kiểm soát.
  • Dynamic popup form (Driver): Khi driver thực hiện action trên đơn hàng, server trả về FormConfig (field definitions, validation, conditional show) — bottom sheet render form động, submit về dynamic endpoint.
  • FCM + Deep Link: Xử lý đủ 3 state (foreground/background/killed). Tap notification → parse URL → navigate đến đúng đơn hàng.
  • Merchant menu CRUD: Hệ thống 3 tầng (group → product → attribute), drag-and-drop reorder, batch update, toggle visibility.
  • Backend-driven actions: Action buttons và form fields do server quyết định — 3 app đồng bộ flow mà không cần release app mới.
  • API layer: Retrofit code generation + Dio interceptor tự inject Bearer token, device metadata, timezone vào mọi request.

VFC 3 — PestMan

Mobile App

Quản lý dịch hại & công việc thực địa — Full Development

Ứng dụng React Native (Expo) xây dựng từ đầu cho nhân viên kiểm soát dịch hại tại nhà máy. Nhân viên dùng app để nhận task, scan QR thiết bị, ghi nhận dữ liệu thực địa và đồng bộ khi có mạng.

  • Offline-first: Toàn bộ dữ liệu form lưu vào SQLite (expo-sqlite) khi mất mạng. Dataset lớn (>10MB) được nén bằng gzip (pako) trước khi ghi — giảm đáng kể dung lượng lưu trữ. Tự động sync khi có kết nối trở lại.
  • Config-driven form: MyFormControlV2 với 20+ control types (text, currency, date, signature, image, QR scan...) render theo config từ server — thêm field mới không cần release app.
  • Device tracking qua QR: Nhân viên scan QR thiết bị → form điền dữ liệu → GPS snapshot → upload ảnh → submit. Hỗ trợ offline queue.
  • Auth: OAuth2 + biometric (expo-local-authentication), token lưu native keychain/keystore.
  • OTA update: expo-updates + EAS — deploy bản vá không cần qua Store review.
